Simple Profit Analysis

Project Overview
This project focuses on analyzing and comparing total profit across different product categories using the Sample Superstore dataset in Microsoft Excel.

Objective
To understand basic profitability by calculating and comparing profits across Furniture, Office Supplies, and Technology categories.

Dataset
- Dataset: Sample Superstore
- Total Records: 9,994
- Key Columns: Category, Sales, Profit

Tools Used
- Microsoft Excel

 Analysis Performed
- Calculated overall sales and total profit.
- Calculated average profit.
- Compared total profit across product categories.
- Calculated category-wise profit margins.
- Created a chart to visualize profit comparisons.

- Technology generated the highest total profit.
- Office Supplies ranked second in total profit.
- Furniture generated the lowest total profit.
- Overall Profit: 286,397.02
- Overall Sales: 2,297,200.86

 Deliverables
1. Profit Summary
2. Profit Comparison Chart
3. Raw Dataset
4. Analysis Notes

 Conclusion
The analysis shows that Technology is the most profitable product category, followed by Office Supplies and Furniture. This project helped in understanding basic profitability analysis and data visualization using Excel.
